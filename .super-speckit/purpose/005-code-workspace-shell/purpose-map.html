HUMAN PURPOSE GATE · DRAFT

Code workspace shell

Code mode is a seamless switch from a bot surface, landing in a dedicated workspace view where terminal, files, preview and git graph are first-class panels outside the computer screen, and an omp session's terminal is a real bash shell with omp already launched inside.

Who this serves

Technically comfortable Rakazo users directing agent implementation on web/Electron; self-hosters running the server.

How success is recognized

One visible Chat-to-Code action ends in the workspace view with a live terminal (view-only until control is taken), files and git panels populated from the workspace, no chat-UI clone for omp.

Explicit non-goals

No ChatGPT-style chat surface for omp; no mid-session engine change; no file editing/diff editor depth; panels degrade truthfully when unsupported.

What confirmation means

Confirm the intent, affected people, success signal, and boundaries. The agent owns technical discovery and delivery after this gate.
