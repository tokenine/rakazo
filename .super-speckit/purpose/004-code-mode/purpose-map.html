HUMAN PURPOSE GATE · DRAFT

Rakazo Code - agent-assisted development workspace

A complete agent-assisted development workspace for technically comfortable users who direct and review implementation: an agent works in an isolated server project environment while the user converses, inspects files and changes, views the running app, uses a terminal, and can take manual control. First journey: improve an existing Linux-compatible JavaScript/TypeScript web repository, verify a substantial feature, and produce a reviewable pull request within granted permissions.

Who this serves

Technically comfortable users directing and reviewing agent implementation, on web and Electron (full workspace), app/CLI (same server-owned coding session), and mobile (applicable conversation, steering, approval, preview, and review workflows through native patterns). Engine choice at session creation: normal Pi or OMP, fixed for that session; self-hosted Linux server execution first.

How success is recognized

The repository-to-PR journey works with each engine: reproducible environment, agreed outcome, implemented and verified feature, inspectable preview and diff, reviewable pull request. Both engines expose prompt, steer, stop, resume, inspect changes, approvals - no silent engine switch. Concurrent tasks do not collide; takeover pauses execution without overwriting either party's work; checkpoint restore protects later manual edits; previews are private and authenticated by default; failures report evidence and blockers truthfully.

Explicit non-goals

ZCode is a functional benchmark, not a visual design or feature-for-feature parity target; Rakazo keeps its own interface and design system. No debugger UI, extension compatibility, or advanced refactoring initially. No promise of arbitrary-process survival across suspension; checkpoints are not universal undo. Engine adoption is not conditional on a comparative winner; unsupported environment requirements are disclosed, not hidden. This draft authorizes no implementation.

What confirmation means

Confirm the intent, affected people, success signal, and boundaries. The agent owns technical discovery and delivery after this gate.
